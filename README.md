# 🚀 Products

## 📮 메일딸깍

**거래처별 마감자료 생성부터 첨부파일 확인과 메일 발송까지 한 번에 처리하는 데스크톱 앱**

반복적인 매출 마감 업무에서 발생하는

`Excel 확인 → 업체별 파일 생성 → 담당자 확인 → 첨부 → 메일 작성 → 발송`

과정을 하나의 워크플로우로 연결했습니다.

### 주요 기능

- Excel 매출 데이터 업로드 및 검증
- 거래처별 마감자료 생성
- 거래처 / 담당자 관리
- 마감 상태 관리
- 수신자 · 금액 · 첨부파일 발송 전 확인
- Gmail / Naver / Outlook / SMTP 메일 연동
- 상황별 메일 템플릿
- 세금계산서 데이터 비교
- 메일 발송 이력 관리
- Windows / macOS 설치 프로그램 배포

### Tech

`React` `Electron` `Node.js` `SQLite` `ExcelJS`

## 🧰 Quick Office Tools

**회사에서 은근히 시간을 많이 잡아먹는 작은 반복 작업을 빠르게 처리하기 위한 무료 데스크톱 도구 모음**

거대한 업무 시스템보다는

> “이거 매번 하기 너무 귀찮은데?”

싶은 작업을 버튼 몇 번으로 끝낼 수 있도록 만드는 프로젝트입니다.

### 주요 기능

- 파일명 일괄 변경
- PDF 관련 반복 작업
- 파일 정리 및 사무 보조 기능
- 로컬 파일 기반 처리
- Windows / macOS 설치 프로그램 배포

새로운 사무 자동화 기능을 계속 추가하고 있습니다.

### Tech

`Vue` `Electron` `JavaScript` `Node.js`

👉 [Quick Office Tools v1.0.0 다운로드](https://github.com/rlahfld54/quick-office-tools-release/releases/tag/v1.0.0)

# 💡 What I Build

```text
반복되는 실무
      ↓
업무 흐름 분석
      ↓
불필요한 단계 발견
      ↓
Desktop App / Automation
      ↓
실제로 사용할 수 있는 제품
```

제가 관심 있는 것은 단순한 **기능 개발**보다  
사용자의 실제 업무 흐름을 이해하고 **병목을 줄이는 소프트웨어를 만드는 것**입니다.

특히 이런 분야에 관심이 있습니다.

- 🖥️ Desktop Application
- ⚙️ Business Automation
- 📊 Excel Automation
- 📄 PDF / File Processing
- ✉️ Email Workflow
- 💾 Offline-First Application
